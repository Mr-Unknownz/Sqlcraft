Supported MySQL Syntax & Data Types Reference

Syntaxes

CREATE; USE; ALTER; SHOW; DROP; ADD; MODIFY; DESCRIBE; CHECK; REFERENCES; INSERT; SELECT; WHERE; DISTINCT; ORDER BY; COUNT; SUM; AVG; MAX; MIN; LIKE; AS; ANY; BETWEEN; NOT,AND,OR; UPDATE; DELETE; ON DELETE CASCADE; ON DELETE SET NULL; ON DELETE RESTRICT;

Numeric Data Types

INT / INTEGER (Standard integer numbers) AUTO_INCREMENT (Automated number raws) BIGINT (Large whole numbers) FLOAT / DOUBLE (Floating-point numbers) DECIMAL(M, D) (Exact fixed-point decimals)

String & Text Types

VARCHAR(n) (Variable-length string) CHAR(n) (Fixed-length string) TEXT / LONGTEXT (Long text blocks)

Date & Time Types

DATE (Format: YYYY-MM-DD) DATETIME / TIMESTAMP (Date & Time) TIME (Format: HH:MM:SS) YEAR (Format: YYYY)

Boolean & Operations

BOOLEAN / BOOL (True/False values)

Database Anomalies & Issues

Insertion Anomaly

Unable to insert data without prior existence of other related data records.

Update Anomaly

Data inconsistency caused by changing details in only some duplicate places.

Deletion Anomaly

Unintended loss of valid data when deleting another unrelated record.

Functional Dependencies Types

Total Functional Dependency

Completely dependent on the entire primary key (not just a part of the key).

Partial Functional Dependency

Another attribute depending solely on a part of a composite primary key.

Transitive Dependency

Depending on a non-primary key attribute in a database table.

Database Normalization & Normal Forms

Zero Normalize Form (0NF)

Raw data containing repeating groups, multi-valued attributes, and no primary key.

1st Normalize Form (1NF)

Atomic values only; no repeating groups; unique primary key for every row.

2nd Normalize Form (2NF)

Must be in 1NF and eliminate partial functional dependencies (Composite keys rule).

3rd Normalize Form (3NF)

Must be in 2NF and eliminate transitive dependencies (Non-key to non-key dependencies).
