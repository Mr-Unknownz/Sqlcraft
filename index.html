Supported MySQL Syntax & Data Types Reference

Databases

CREATE; USE; ALTER; SHOW; DROP; ADD; MODIFY; DESCRIBE; CHECK; REFERENCES; INSERT; SELECT; UPDATE; DELETE;

Numeric Data Types

INT / INTEGER (Standard integer numbers) AUTO_INCREMENT (Automated number raws) BIGINT (Large whole numbers) FLOAT / DOUBLE (Floating-point numbers) DECIMAL(M, D) (Exact fixed-point decimals)

String & Text Types

VARCHAR(n) (Variable-length string) CHAR(n) (Fixed-length string) TEXT / LONGTEXT (Long text blocks)

Welcome to SQLCraft

A lightning-fast, zero-setup in-memory MySQL grammar simulator built entirely for developers, students, and educators.

Created by Bhashana Sandesh

100% Client-Side

Runs directly inside your browser using pure JavaScript memory storage without needing any backend server infrastructure.

Learn & Practice

Ideal for learning fundamental SQL commands, relational schemas, database navigation, and table structure manipulations safely.

Advanced Engine

Supports all standard MySQL data types, auto-incrementing identifiers, check constraints, column alterations, sorting, and row limits seamlessly.
